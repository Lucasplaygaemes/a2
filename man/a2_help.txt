# a2 - A Modal Text Editor

a2 is a modal editor for the Linux terminal, written in C from scratch.
It brings together modal editing, LSP capabilities, and terminal integration in a lightweight native package.

## Features

- Normal, insert, visual, and command modes.
- Splits, layouts, and workspaces.
- Fuzzy finder (`Alt+f`), command palette (`Alt+t`), file explorer (`Alt+e` or `:explorer`).
- LSP client (diagnostics, completion, hover, definition, rename, code actions), if you have a language server configured.
- Plugins: shared libraries loaded from `~/.a2/plugins/`. `make` builds the ones in `plugins/` into that directory.
- Themes, a settings panel (`:settings`), and keybindings. Your overrides are saved in `~/.a2/sc.a2`. The shipped defaults are `ds.a2`, and they match `default_bindings` in `a2_files/defs.c`.
- Spell checking (Hunspell, dlopen) and a Wiktionary lookup (`D` in normal mode, needs libcurl).
- Integrated terminal (`:term`) via libvterm, plus a floating terminal (`Alt+F12`).
- Git gutter and safe external command execution (`process_exec`).
- Macros (`q`, `@`), local history (`:history`), and project sessions (`:save-project`).

## Architecture & Key Notes

- Syntax files configure keywords, types, standard library functions, and per-language comment delimiters (`COMMENT_LINE`, `COMMENT_BLOCK_START`, `COMMENT_BLOCK_END`).
- Keybinding priorities: `Alt+Shift+S` opens Show Symbols. To access the full settings panel, use `:settings`.
- Text navigation: motion uses `k` (left), `ç` (right), `o` (up), `l` (down), in addition to the standard arrow keys. See the shortcuts page.
- Reverse engineering tools: binary analysis features leverage external utilities (`r2`, `readelf`, `nm`) via plugins when installed on `PATH`.

## Hard limits

- 32768 lines per buffer. The rest of the file is discarded on open.
- 4095 bytes per read chunk. A longer source line is split into several editor lines.
- 512 undo levels, each a full copy of the buffer.
- Filename stored in the buffer: 255 bytes.

## Platform

Linux. Not ported to Windows. macOS is untested.
Install with `./install.sh` from a clone. Help texts are installed to `/usr/local/share/a2/man/`.
