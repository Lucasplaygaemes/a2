# a2 Shortcuts Manual

This page lists the keyboard shortcuts for the `a2` editor.

**Note:** All shortcuts below are the defaults. You can customize every action in the editor by going to *Alt+S > Keybindings*. Your changes will be saved to `~/.a2/sc.a2`.

## Global Shortcuts
- *Alt+T* : Open the unified Command Palette.
- *Alt+F* : Open the Fuzzy Finder to search for project files.
- *Alt+B* : Show a list of recently opened files.
- *Alt+S* : Start a project-wide content search (grep).
- *Alt+A* : Compile and view assembly side-by-side with source.
- *Alt+$* : Jump to the end of the line (Works in Insert Mode).
- *Alt+0* : Jump to the start of the line (Works in Insert Mode).
- *Alt+X* : Close the active window.
- *Alt+Enter* : Create a new empty window (vertical split).
- *Alt+Space* : Open a new terminal window.
- *Ctrl+]* / *Ctrl+[* : Navigate to the next/previous window (split).
- *Alt+N* / *Alt+M* : Navigate to the next/previous workspace.
- *Ctrl+W* : Create a new empty workspace.
- *Alt+[1-9]* : Move the active window to the specified workspace.
- *Alt+.* : Cycle through available window layouts.
- *Alt+R* : Rotate windows within the current layout.
- *Ctrl+Shift+M* : Toggle Movable Hover Mode for LSP diagnostics and spell-checking popups. Use arrows/mouse to move, Enter to pin, Esc to close.
- *Alt+Shift+I* : Toggle image preview hover for the Markdown image link under cursor.
- *Ctrl+Enter* : Open the Markdown image link under cursor in a new window split.
- *Space, Enter* : Open a new terminal on a side window split (`:termside`).

## Normal Mode
- *i* : Enter *Insert Mode*.
- *v* : Enter *Visual Mode*.
- *V* : Enter *Visual Line Mode*.
- *Ctrl+V* : Enter *Visual Block Mode*.
- *:* : Enter *Command Mode*.
- *h, j, k, l* / *Arrows* : Move cursor left, down, up, right.
- *{ / }* : Jump to previous / next paragraph (separated by blank lines).
- *%* : Jump to the matching bracket `()`, `[]`, `{}`.
- *g* / *G* : Jump to the start / end of the file.
- *K* / *Home* : Jump to the start of the line.
- *Ç* / *End* : Jump to the end of the line.
- *O* / *L* / *PageUp* / *PageDown* : Page up/down.
- *w* : Move to the start of the next word.
- *b* : Move to the start of the previous word.
- *e* : Move to the end of the current/next word.
- *Alt+W* / *Alt+Q* : Same as *w* / *b* (also works in Insert Mode).
- *f{char}* : Jump forward to the next occurrence of *{char}* on the line.
- *F{char}* : Jump backward to the previous occurrence of *{char}* on the line.
- *t{char}* : Jump forward to just *before* the next occurrence of *{char}*.
- *T{char}* : Jump backward to just *after* the previous occurrence of *{char}*.
- *;* : Repeat the last *f/F/t/T* motion in the same direction.
- *,* : Repeat the last *f/F/t/T* motion in the opposite direction.
- *[count]* : Type a number before any motion or operator to repeat it. Example: *3w* moves 3 words, *5j* moves 5 lines down.
- *u* / *U* : Create a new line above/below and enter Insert Mode.
- *J* : Join the current line with the line below.
- *yy* / *[N]yy* : Yank (copy) N lines to the local register (default: 1).
- *p* / *P* : Paste from local / global register after the cursor.
- *m* : Paste from the "move" register (used after cutting in Visual Mode).
- *q[a-z]* : Start or stop recording a macro.
- *@[a-z]* : Play back a macro. *@@* repeats the last one.
- *Ctrl+f* / */* : Unified interactive search. Opens the command bar with */*. Use *Arrows* to move the cursor and *Up*/*Down* to navigate search history.
- *Ctrl+d* / *Ctrl+a* : Find next / previous occurrence of the last search.
- *Ctrl+Del* / *Ctrl+k* : Delete the current line.
- *Alt+c* : Toggle comment on the current line or visual selection.
- *Alt+C* : Change inside (prompts for ", ', (, [, {, <) and enter Insert Mode.
- *Alt+D* : Delete inside (prompts for ", ', (, [, {, <).
- *D* : Fetch and display the Wiktionary definition of the word under cursor.
- *Alt+Backspace* : Delete the previous word (Works in Insert Mode).

### Marks
- *m{a-z}* : Set mark `{a-z}` at the current cursor position.
- *'{a-z}* : Jump to the line of mark `{a-z}` (first non-blank character).
- *`{a-z}* : Jump to the exact position (line and column) of mark `{a-z}`.
- *''* / *``* : Jump back to the position before the last mark jump.

### Composable Operators (Normal Mode)
Operators combine with motions, counts, and text objects: `[count] operator [motion | text-object]`.

- *d{motion}* : Delete from cursor to where *{motion}* lands. Examples: *dw*, *d3j*, *df,*, *diw*.
- *dd* / *[N]dd* : Delete N full lines (default: 1).
- *y{motion}* : Yank (copy) from cursor to where *{motion}* lands. Examples: *yw*, *y}*, *yiw*.
- *c{motion}* : Change (delete + enter Insert). Examples: *cw*, *ct"*, *ciw*.
- *cc* : Clear the current line and enter Insert Mode.
- *>{motion}* : Indent the lines covered by *{motion}*. Examples: *>>* (current line), *>3j*, *>ip*.
- *<{motion}* : Un-indent the lines covered by *{motion}*. Examples: *<<*, *<3j*, *<ip*.
- *r{char}* : Replace the character under cursor with *{char}*, stay in Normal Mode. With count: *3rX* replaces 3 chars with X.
- *x* / *[N]x* : Delete N characters under/after the cursor.
- *X* / *[N]X* : Delete N characters before the cursor.
- *s* / *[N]s* : Delete N characters and enter Insert Mode.
- *S* : Clear the current line and enter Insert Mode (same as *cc*).

### Text Objects (use after an operator + *i* or *a*)
- *iw / aw* : Inner word / a word (with surrounding space).
- *i( / a(* : Inner / outer parentheses.
- *i[ / a[* : Inner / outer brackets.
- *i{ / a{* : Inner / outer braces.
- *i" / a"* : Inner / outer double quotes.
- *i' / a'* : Inner / outer single quotes.

## Insert Mode
- *Esc* : Return to *Normal Mode*.
- *Ctrl+o* : Enter Normal Mode for a single command, then return to Insert.
- *Tab* : Context-aware: Indents if at start of line, offers spelling suggestions if on a misspelled word, otherwise triggers completion.
- *Shift+Tab* : Un-indent the current line.
- *(*, *[*, *{*, *"* : Auto-close the pair and place the cursor inside.
- *Ctrl+P* : Create a new line above the current line.
- *Ctrl+L* : Create a new line below the current line.
- *Ctrl+U* / *Ctrl+R* : Undo / Redo.
- *Ctrl+V* : Paste from the local yank register.
- *Alt+S* : (During completion) Expand the selected suggestion as a snippet.

## Visual Mode
- *Esc* : Exit Visual Mode and return to Normal Mode.
- *s* : Start or end a character-wise selection.
- *w* : Extend selection to the start of the next word.
- *b* : Extend selection back to the start of the previous word.
- *e* : Extend selection to the end of the current/next word.
- *f{char}* / *F{char}* : Extend selection forward/backward to *{char}*.
- *t{char}* / *T{char}* : Extend selection forward/backward to just before/after *{char}*.
- *;* / *,* : Repeat last *f/F/t/T* in same / opposite direction.
- *y* : Yank (copy) the selected text to the local register.
- *Ctrl+y* : Yank the selected text to the global register.
- *Alt+y* : Copy the selection to the system clipboard.
- *m* : Cut the selection to the "move" register.
- *p* : Paste over the selection.
- *>* / *<* : Indent / un-indent the selected block.
- *Alt+Tab* / *Shift+Tab* : Indent / un-indent the selected block.
- *Alt+c* : Toggle comments on all lines in the selection.

## File Explorer Mode
- */* : Filter files and directories by name.
- *j, k*, *Arrows* : Navigate up and down.
- *Enter* : Open a file or enter a directory.
- *r* : Rename the selected item.
- *n* / *N* : Create a new file / directory.
- *c* / *x* / *v* : Copy / Cut / Paste files and directories.
- *d* : Delete the selected item (with confirmation).
- *.* / *h* : Toggle hidden files.
- *Space* : Toggle selection (multiselect).
- *D* : Diff selected file(s). If 2 files selected, diffs them. If 1, diffs vs HEAD.
- *P* : Preview file (first 40 lines).
- *b* : Git Blame the selected file.
- *x* : Execute file (if executable).
- *a* : Git Add (Stage) selected file.
- *u* : Git Unstage (Restore) selected file.
- *c* : Git Commit (prompts for message).
- *p* : Git Push.
- *q* : Close the explorer window.

## Multi-Cursor
- *Alt+Shift+Up* : Add an extra cursor on the line above.
- *Alt+Shift+Down* : Add an extra cursor on the line below.
- *Middle Mouse Click* : Add an extra cursor exactly where you click.
- *Esc* : Clear all extra cursors and return to a single cursor.

## Multi-key Sequences (ALT)
Press the first key, release, then press the second.
- *Alt+d, f* : Go to the definition of an function with lsp.
- *Alt+d, d* : Open a new workspace and start a GDB session.
- *Alt+d, e* : Open the Fuzzy Finder (same as *Alt+f*).
- *Alt+g, g* : Open the directory navigator.
- *Alt+g, a* : Run `git add -u` in a new terminal window.
- *Alt+g, s* : Run `git status` in a new terminal window.
- *Alt+p, c* : Paste from the system clipboard.
- *Alt+p, a* / *Alt+p, u* : Paste the editor's local buffer above/below the current line.
- *Alt+p, P* / *Alt+p, U* : Paste the editor's global buffer above/below the current line.
- *Alt+y, p* : Yank (copy) the current paragraph.
