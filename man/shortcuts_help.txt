# a2 Shortcuts Manual

Defaults below come from `ds.a2`, which matches `default_bindings` in `a2_files/defs.c`.
Personal changes are saved to `~/.a2/sc.a2` and override this file.
If you already have a `~/.a2/sc.a2` from an older build, these defaults do not apply until you delete that file or run `:shortcuts-reset`.

`:ksc` prints the table the running process is actually using. Trust that over this page if you have customized keys.

## Collisions in the default table

The dispatcher returns the first matching action.

- `Alt+Shift+S` is bound to Show Symbols, Expand Snippet, and Settings. Show Symbols wins. Open settings with `:settings`.
- `Alt+$` is bound to "end of line" and "move window to position 4". End of line wins.
- `Alt+d` is a two-key leader. The Directory Navigator binding on bare `Alt+d` never runs. `Ctrl+G` opens the directory navigator (hardcoded in normal mode).

## How a text window moves

This is not Vim's hjkl.

- `k` or Left: left
- `ç` or Right: right
- `o` or Up: up
- `l` or Down: down
- `O` or Page Up: ten lines up
- `L` or Page Down: ten lines down
- `K` or Home: start of the line
- `Ç` or End: end of the line
- `g` / `G`: first / last line
- `w` / `b` / `e`: next word / previous word / end of word
- `Alt+w` / `Alt+q`: same word motions, also from insert mode
- `{` / `}`: previous / next paragraph
- `%`: matching bracket
- `f{char}` `F{char}` `t{char}` `T{char}`: find on the line. `;` repeats, `,` reverses

`h` and `j` do not move the cursor in a text window. In the file explorer, `j` and `k` do.

## Global

- `Alt+t`: command palette
- `Alt+f`: fuzzy finder
- `Alt+b`: recent files
- `Alt+e`: file explorer
- `Alt+s`: project grep
- `Alt+a`: assembly view of the current C file
- `Alt+l`: LLVM IR view
- `Alt+x`: close the window
- `Alt+Enter`: new editor split
- `Alt+Space`: new terminal split
- `Space`, then `Enter`: terminal in a side split
- `Ctrl+]`: next window
- `Ctrl+[`: previous window
- `Ctrl+W`: new workspace
- `Alt+m`: next workspace
- `Alt+n`: previous workspace
- `Alt+1` through `Alt+9`: switch workspace
- `Alt+.`: cycle layout
- `Alt+r`: rotate windows
- `Alt+F12`: floating terminal
- `Alt+h`: move a visible hover popup (arrows or mouse, Enter pins, Esc closes)
- `Alt+Shift+I`: markdown image hover
- `Ctrl+Enter`: open the markdown image under the cursor in a split
- `Alt+0` / `Alt+$`: start / end of line
- `:help`, `:ksc`, `:settings`: help, this list, settings. They have no default key (`HELP` and `KSC` are unbound).

## Normal mode

- `i`: insert mode. `a`, `A`, `I`, `o`, and `O` do not enter insert. `o` moves up. `O` pages up.
- `v`: visual mode. `V`: visual line. `Ctrl+V`: visual block.
- `:`: command mode
- `/` or `Ctrl+f`: search bar
- `Ctrl+d` / `Ctrl+a`: find next / previous
- `Ctrl+k` or `Ctrl+Delete`: delete the line
- `Ctrl+u` / `Ctrl+r`: undo / redo. `u` is not undo.
- `J`: join with the next line
- `yy`, `dd`, `cc`: yank / delete / change the line, with a count (`3dd`)
- `d`, `y`, `c`, `>`, `<` plus a motion or a text object (`iw`, `i"`, `i(`, `i{`)
- `x` / `X`: delete character after / before the cursor
- `r{char}`: replace character. `s`: delete character and insert. `S`: clear the line and insert.
- `p` / `P`: paste local / global register
- `m{a-z}`: set a mark. `'{a-z}` jumps to the line, `` `{a-z} `` jumps to the exact column. `''` jumps back.
- `q` then a letter: record a macro. `q` again: stop. `@` then the letter: play. `@@`: replay.
- On a read-only or scratch buffer, `q` closes the window instead of recording.
- `D`: Wiktionary lookup of the word under the cursor
- `Alt+c`: toggle comment
- `Alt+C`: change inside a delimiter
- `Alt+D`: delete inside a delimiter
- `Alt+Backspace`: delete the previous word
- `Alt+w`: save
- `Ctrl+Alt+Up` / `Ctrl+Alt+Down`: add a cursor on the line above / below. Middle click also adds one. `Esc` clears extra cursors.
- On a conflict marker line, `m` keeps mine and `t` keeps theirs. `[` / `]` jump between markers.
- `Ctrl+G`: directory navigator

## Insert mode

- `Esc`: normal mode
- `Ctrl+o`: one normal command, then back to insert
- `Tab`: indent at the start of the line, spell suggestions on a misspelled word, otherwise completion
- `Shift+Tab`: unindent
- `(` `[` `{` `"`: insert the closing pair
- `Ctrl+u` / `Ctrl+r`: undo / redo
- `Ctrl+v`: paste the local register

## Visual mode

- `Esc` or `v`: back to normal
- `y`: yank the selection. `Ctrl+y`: yank to the global register
- `Alt+y`, then `c`: copy to the system clipboard (needs wl-copy, xclip, or xsel)
- `d`: delete the selection
- `>` / `<` or `Alt+Tab` / `Shift+Tab`: indent / unindent
- `Alt+c`: toggle comments on the selection
- Motions `w` `b` `e` `f` `F` `t` `T` extend the selection

## File explorer

`j` / `k` here are down / up. That is the opposite of the text window.

- `/`: filter. `Esc`: clear the selection, or leave the filter, or move to the previous window
- `Enter`: open
- `n` / `N`: new file / new directory
- `r`: rename
- `c` / `x` / `v`: copy / cut / paste
- `d`: delete, after a confirmation
- `.` or `h`: hidden files
- `Space`: select, and move down
- `D`: diff (two selected files, or the current file against `HEAD`)
- `P`: toggle the preview
- `b`: git blame
- `X`: run the file if it is executable
- `a`: git add
- `u`: git unstage (`git restore --staged`)
- `C`: git commit. Lowercase `c` is copy, not commit.
- `p`: git push
- `q`: close the explorer

## Two-key sequences

Press `Alt+<leader>`, release, then the second key. `Esc` cancels.

- `Alt+d`, then `d` `b` `r` `n` `s` `c` `p` `w` `t` `k`: GDB start, break, run, next, step, continue, print, watch, TUI, quit
- `Alt+d`, then `a`: LSP code action
- `Alt+d`, then `f`: LSP go to definition
- `Alt+d`, then `l`: compile the current file to a `.s`
- `Alt+g`, then `s`: git status
- `Alt+g`, then `a`: git add -u
- `Alt+g`, then `d`: interactive diff
- `Alt+p`, then `c`: paste from the system clipboard
- `Alt+p`, then `a` / `u`: paste the local register above / below
- `Alt+p`, then `P` / `U`: paste the global register above / below
- `Alt+p`, then `r`: repeat text
- `Alt+p`, then `t`: generic input prompt
- `Alt+y`, then `p`: yank the paragraph
- `Alt+y`, then `c`: yank to the system clipboard

`Alt+d`, then `e` is not a shortcut. Fuzzy find is `Alt+f`.
