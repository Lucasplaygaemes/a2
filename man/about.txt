# a2 Text Editor

A2 is a modal terminal text editor written in C, inspired by Vim and Emacs.
It combines modal ergonomics, LSP support, terminal splits, and plugin extensibility.

## Dependencies & Architecture

- Ncursesw: terminal UI and keyboard input. Linked.
- libvterm: integrated terminal emulation. Linked. Built from source by install.sh if missing.
- Jansson: JSON parser for LSP communications and session state. Linked.
- stb_image: image rendering. Vendored in a2_files/stb_image.h (public domain / MIT).

Loaded at runtime with dlopen:

- libcurl: dictionary lookups.
- Hunspell: real-time spell checking.

External tools (optional):

- git, gcc, clang, and clipboard utilities (wl-copy, xclip, xsel).
- radare2: binary analysis suite used by plugins/plugin_re_suite.c.
  The decompilation feature leverages `r2 -c pdg` (r2ghidra).

## Current Buffer Limits

In the current line-array buffer implementation:
- Maximum line capacity: 32768 lines.
- Source lines exceeding 4095 bytes are partitioned across lines.
- Undo history retains up to 512 buffer snapshots.
- Buffer filenames are bounded at 255 bytes.
(A piece-table architecture pass is in progress to remove static limits.)
